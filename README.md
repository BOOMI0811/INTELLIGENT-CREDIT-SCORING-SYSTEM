# Intelligent Credit Scoring System

Real-time credit default prediction using LendingClub loan data.

## Dataset
- Source: LendingClub (Loan_Data.csv)
- Features: credit_lines, loan_amt, total_debt, income, years_empl, fico_score
- Target: default (0/1)

## Model
- Algorithm: Random Forest Classifier
- Accuracy: ~89%
- Train/Test Split: 80/20

## How to run
pip install pandas scikit-learn
python train_model.py
